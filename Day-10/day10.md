# 🚀 Day 10 – AI Portfolio Website Challenge

## Objective

Build a modern, responsive personal portfolio website using Claude AI and Prompt Engineering.

---

## Prompt Used

Created a complete portfolio website using a detailed prompt containing:

* Personal Information
* Skills
* Projects
* Achievements
* Design Preferences
* Portfolio Requirements

Claude generated a complete single-file HTML portfolio using:

* HTML
* Tailwind CSS (CDN)
* Vanilla JavaScript

## Learnings

1. Prompt quality significantly impacts AI-generated website quality.
2. Claude can generate complete front-end applications from a single detailed prompt.
3. Tailwind CSS helps create modern and responsive UI designs quickly.
4. Personal branding is important for internships and job opportunities.
5. AI can accelerate web development and prototyping workflows.
6. Iterative prompting helps improve design, structure, and content quality.

* Organizing project details effectively.

Successfully generated, tested, and documented a professional portfolio website suitable for showcasing skills, projects, and achievements to recruiters and employers.
