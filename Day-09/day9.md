# 🚀 Day 9 – NutriScope Application Development

## Objective
Build and compare two versions of a nutrition tracking application using Claude AI:
1. NutriScope MVP (v1.0)
2. NutriScope Enhanced (v2.0)

---

## Prompt 1 – MVP Version

### Features Implemented
- User Profile Inputs
  - Age
  - Gender
  - Height
  - Weight
  - Activity Level
  - Dietary Preference

- Food Logging
  - Add Food
  - Quantity & Unit Selection
  - Editable Food Table
  - Remove Entries

- Nutrition Tracking
  - Calories
  - Protein
  - Carbs
  - Fat
  - Fiber
  - Iron
  - Calcium
  - Vitamin C
  - Vitamin D
  - Vitamin B12

- Dashboard
  - Energy Progress
  - Macro Distribution Chart
  - Nutrient Completion
  - Deficiencies
  - Excesses

---

## Key Learnings

1. AI can generate complete web applications from detailed prompts.
2. Better prompts produce significantly better outputs.
3. Feature enhancement prompts can transform a basic MVP into a more professional application.
4. Single-file HTML projects are useful for rapid prototyping.
5. Iterative prompting is an effective development workflow.
