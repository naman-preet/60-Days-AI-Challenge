# Day 35 – Prompt Puzzle

## Objective
Built and tested an interactive Prompt Puzzle application to improve AI prompting skills through gamified challenges.

## Features
- Offline single-file HTML application
- Domain-specific randomized scenarios
- Three interactive challenge types
- Drag-and-drop prompt building
- Live scoring system
- Prompt Performance Report
- Replay with new scenarios

## Challenges Completed
1. Build the Prompt
2. Clean the Prompt
3. Choose the Best Prompt

## What I Learned
- Writing structured AI prompts
- Identifying weak vs. optimized prompts
- Applying prompt engineering principles
- Improving prompt clarity and specificity
- Evaluating AI outputs effectively

## Key Takeaways
- Context improves AI responses.
- Clear instructions reduce ambiguity.
- Well-structured prompts produce better results.
- Simplicity often outperforms over-engineering.

## Outcome
Successfully generated, tested, and replayed the Prompt Puzzle application with multiple scenarios.
