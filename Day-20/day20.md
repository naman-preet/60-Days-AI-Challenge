# Day 20 – Face Puzzle Game

## Objective

Today, I built a Face Puzzle Game using AI-assisted development with Claude. The application captures a user's photo through the webcam and converts it into an interactive puzzle game with multiple difficulty levels.

## Features Implemented

* Webcam access using `getUserMedia()`
* Live camera preview
* Photo capture functionality
* Difficulty selection (3×3, 4×4, 5×5)
* Puzzle piece generation from captured image
* Drag-and-drop support
* Touch gesture support for mobile devices
* Timer with live updates
* Move counter
* Correct piece tracker
* Automatic win detection
* Results screen
* LocalStorage leaderboard
* Responsive design
* Retake Photo option
* Play Again functionality
* New Photo option

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Canvas API
* WebRTC (getUserMedia)
* LocalStorage

## Development Process

1. Generated the complete application using Claude.
2. Saved the generated code as a single HTML file.
3. Opened the application in the browser.
4. Granted webcam permissions.
5. Captured a photo using the camera.
6. Selected puzzle difficulty.
7. Tested drag-and-drop functionality.
8. Verified touch controls on mobile devices.
9. Checked timer, move counter, and leaderboard features.
10. Completed the puzzle and reviewed the final results.

## Key Learnings

* Working with browser camera APIs.
* Using Canvas API for image processing.
* Splitting images into puzzle pieces.
* Implementing drag-and-drop interactions.
* Handling touch events for mobile devices.
* Managing game state using JavaScript.
* Storing and retrieving data using LocalStorage.
* Building responsive user interfaces.

## Challenges Faced

* Managing puzzle piece positioning.
* Ensuring smooth drag-and-drop interactions.
* Maintaining responsive layouts across devices.
* Implementing accurate win detection logic.

## Outcome

Successfully created a fully functional Face Puzzle Game that allows users to capture their own image, generate a puzzle, track performance, and save best scores locally.
